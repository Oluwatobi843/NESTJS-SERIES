# NestJS Series

> A structured learning repository documenting backend development concepts with TypeScript and NestJS.

## Overview

NestJS Series is a learning-focused repository for building familiarity with the architecture and conventions used in NestJS backend applications. It provides a progression from core framework concepts toward patterns used in larger APIs.

## Learning focus

- Modules
- Controllers
- Providers and services
- Dependency injection
- REST APIs
- TypeScript backend patterns
- Application configuration
- Testing concepts

## Architecture concepts

```text
Request
  |
  v
Controller
  |
  v
Service / Provider
  |
  v
Data or external service
  |
  v
Response
```

NestJS modules provide boundaries around related functionality while dependency injection manages service dependencies.

## Development

```bash
git clone https://github.com/Oluwatobi843/NESTJS-SERIES.git
cd NESTJS-SERIES
npm install
npm run start:dev
```

## Testing

```bash
npm run test
npm run test:e2e
npm run test:cov
```
